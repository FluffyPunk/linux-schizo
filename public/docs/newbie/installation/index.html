    Встановлення системи

    Незалежно від дистрибутиву, процес встановлення зазвичай складається з ключових пунктів:

    • Підготовка носія для встановлення
    • Завантаження Live-середовища
    • Процес встановлення системи

    В контексті самого ж процесу встановлення, завжди присутні кілька основних етапів:

    • Вибір мови та регіональних налаштувань
    • Розмітка диска та вибір файлової системи
    • Налаштування користувачів та паролів
    • Встановлення додаткового програмного забезпечення

    Підготовка до встановлення

    Перед початком встановлення системи необхідно підготувати флешку для запису Live-середовища(або інсталятора, якщо дистрибутив не передбачає Live-середовище). Для цього слід завантажити образ обраного дистрибутиву з офіційного сайту і записати образ на носій за допомогою спеціальних програм (їх достатньо, зробіть запит у пошуковику “програми для запису образу на USB”). Після цього можна переходити до завантаження Live-середовища з підготовленого носія. І тут варто зупинитись на окремих пунктах, оскільки просто взяти і завантажити образ з флешки не вдасться у разі певних нюансів:

    • В BIOS вимкнено завантаження з USB(це навряд, однак варто перевірити Boot from USB)
    • Можливо, у меню вибору носія не буде відображатись флешка, якщо ввімкнено Fast Boot(ця функція доволі шкідлива для Linux)
    • Secure Boot - зло для Linux(в переважній більшості, дивіться доступність цієї функції для вашого дистрибутиву)

    Після цих перевірених функцій можна завантажити носій встановлення. Якщо записаний попередньо файл мав приписку live(або така згадка була на сайті), то такий образ надасть змогу частково дослідити функціонал системи.

    Розмітка дисків

    Цей етап трохи відрізняється порівняно з Windows, оскільки Windows вимагає лише вказати той розділ, на якому буде встановлена система. При встановленні Linux є можливість не лише виділити системні ресурси, але й одразу розподілити диски під інші шляхи або приєднати вже існуючі. Тобто те, що у Windows було диском D і зберігало, наприклад, ігри, на Linux можна приєднати як /mnt/Games і ці файли можливо використати на Linux.

    Однак для початку є два обов’язкових моменти - системні розділи та файлові системи.

    Приклади застосування Системні та допоміжні розділи Linux Переважно системні розділи Розділи, що використовуються на обох системах, в т.ч. зовнішні носії

    Щодо системних розділів, то іноді дистрибутиви надають змогу автоматичного форматування, як і з повним використанням місця системою, так і випадки встановлення системи поряд з Windows на один носій. Однак в таких випадках додаткове налаштування розділів пам’яті відбуватиметься лише після встановлення системи. Тому найкращий метод - самостійний розподіл пам’яті.

    Системний розділ Рекомендований розмір Нотатка
    / ~100GB Це кореневий розділ системи, в ньому зберігатиметься уся основна інформація системи - програми, конфігурації, бібліотеки тощо
    /boot 1-6GB(залежно від завантажувача) Розділ, який відповідатиме за завантаження системи
    /home На ваш розсуд Розділ з файлами вашого користувача, варто зберігати окремо, щоб у разі перевстановлення всі користувацькі конфігурації та завантаження збереглись

    Процедури після встановлення

    Зазвичай вся подальша процедура залежить від того, яким чином подається встановлення системи - онлайн чи офлайн, однак для обох випадків кроки лишнім не буде. Варто оновити системні компоненти до останніх наданих версій. Для цього потрібно відкрити термінал та вписати:

    • для Debian/Ubuntu дистриубтивів sudo apt update && sudo apt upgrade -y
    • для Fedora sudo dnf upgrade --refresh -y
    • для Arch sudo pacman -Syu або за наявних AUR інструментів paru або yay

    У випадку іммутабельної системи, передбачено оновлення графічним інтерфейсом.
