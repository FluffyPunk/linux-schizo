# Вибір дистрибутиву

Дуже частим питанням є вибір дистрибутиву, оскільки Linux - це варіативність. У виборі дистрибутиву варто враховувати потреби користувача, рівень його досвіду та бажану начинку системи.
Саме тому варто обрати дві речі - базовий дистрибутив та робоче середовище.

## Дистрибутиви Linux

Основних незалежних дистрибутивів Linux декілька і вони формують основу для багатьох похідних дистрибутивів. Їх варто розглядати як чисті основи для формування власних середовищ.

### Debian

Debian є одним з найстаріших і найстабільніших дистрибутивів Linux. Його принцип оновлення полягає у ретельному тестуванні пакетів перед їх включенням до стабільної гілки, що забезпечує високу надійність системи. Тому глобальні релізи Debian виходять рідше за інші дистрибутиви, але користувачі отримують більш стабільну систему. Така система переважно підходить для серверів або робочих станцій, де стабільність важливіша за найновіше програмне забезпечення.

У системах на основі Debian, використовується пакетний менеджер APT, а також файлові пакети у форматі .deb для встановлення програмного забезпечення. В контексті похідних систем, можуть існувати користувацькі репозиторії для розміщення додаткового програмного забезпечення, яке не входить до офіційних репозиторіїв.

### Fedora

Fedora є дистрибутивом, який відомий своєю сучасністю та швидким впровадженням нових технологій. Він підтримується спільнотою Red Hat і поєднує в собі більш нові оновлення програмного забезпечення з відносно стабільною базою системи. Це робить Fedora привабливим вибором для користувачів, які хочуть мати доступ до новітніх технологій без значного ризику нестабільності.

У Fedora використовується пакетний менеджер DNF, а також файлові пакети у форматі .rpm для встановлення програмного забезпечення. Fedora також має власні репозиторії з додатковим програмним забезпеченням, а користувачі можуть підключати сторонні репозиторії для розширення функціональності системи. Однак в порівнянні з Debian, пакетна система Fedora є менш інтуїтивно зрозумілою для новачків.

### Arch Linux

Arch Linux є дистрибутивом, який відомий своєю гнучкістю та принципом "rolling release", що означає постійне оновлення системи без необхідності повних перевстановлень. Це дозволяє користувачам завжди мати доступ до найновіших версій програмного забезпечення, але вимагає більшої уваги до стабільності системи.

У Arch Linux використовується пакетний менеджер pacman, який містить порівняно більшу кількість пакетів у офіційних репозиторіях. Також у налаштування пакетного менеджеру можна додавати користувацькі репозиторії для розширення джерел програмного забезпечення та доступу до додаткових пакетів, які не входять до офіційних репозиторіїв. Крім того, Arch Linux має спільноту користувачів, яка активно підтримує AUR (Arch User Repository) - великий репозиторій користувацьких пакетів, що дозволяє легко встановлювати програмне забезпечення, яке не доступне в офіційних репозиторіях.

Також значним плюсом Arch Linux є велика оптимізація ресурсів, що дозволяє ефективно використовувати апаратне забезпечення навіть на старих або малопотужних комп'ютерах. Мінімальні вимоги щодо оперативної пам'яті складають приблизно 512 МБ, однак в реальному прикладі чиста система споживає близько 1 ГБ оперативної пам'яті, що все ще є одним з найкращих показників серед сучасних дистрибутивів Linux.

Однак варто враховувати, що Arch Linux може бути складнішим для новачків через відсутність готових налаштувань та необхідність більш глибокого розуміння системи для її належного функціонування. Окремим елементом уваги є той самий AUR, оскільки пакети з нього іноді компілюються на вашому комп'ютері за заданими інструкціями, які можуть містити шкідливий код. Тому перед встановленням пакетів з AUR варто уважно перевіряти їх вміст та використовувати допоміжні інструменти.

### NixOS

NixOS є дистрибутивом, який відомий своєю унікальною концепцією управління конфігурацією та пакетами. У NixOS використовується пакетний менеджер Nix, який дозволяє встановлювати пакети в ізольовані середовища, що забезпечує високу стабільність та відтворюваність системи. Всі налаштування системи зберігаються у єдиному конфігураційному файлі, що спрощує управління та відновлення системи.

Така архітектура дозволяє легко відновлювати систему до попереднього стану та експериментувати з різними конфігураціями без ризику пошкодження основної системи. Однак NixOS може бути складнішим для новачків через нетрадиційний підхід до управління пакетами та конфігураціями, що вимагає певного часу для освоєння.

## Деривативи

Це дистрибутиви, які базуються на інших основних дистрибутивах, успадковуючи їхні характеристики та додаючи власні зміни або покращення. Наприклад, Ubuntu є деривативом Debian, а Fedora має свої похідні, такі як Bazzite. Деривативи часто намагаються зробити систему більш зручною для користувачів або додати специфічні функції, які відсутні в оригінальному дистрибутиві.

### Ubuntu

Ubuntu є одним з найпопулярніших деривативів Debian і відомий своєю зручністю для користувачів та широкою підтримкою апаратного забезпечення. Він пропонує регулярні випуски з тривалим терміном підтримки (LTS), що робить його привабливим вибором для новачків та користувачів, які цінують стабільність. Ubuntu також має власний пакетний менеджер APT і великий репозиторій програмного забезпечення, що спрощує встановлення та оновлення програм.

Однак варто враховувати, що Ubuntu вважається одним з найбільш "важких" дистрибутивів через велику кількість попередньо встановленого програмного забезпечення та власні модифікації, що сильно впливають на продуктивність системи. Після одного з останніх оновлень на сайті мінімальні системні вимоги були підвищені, що також слід враховувати при виборі цього дистрибутиву.

### Bazzite

Bazzite є деривативом Fedora, націлений на побудову ігрової системи з оптимізованою продуктивністю та зручним інтерфейсом для геймерів. Він зберігає певні основні характеристики Fedora, однак використовує збірку Atomic, яка містить іммутабельні (незмінні) системні компоненти, що забезпечує стабільність та безпеку системи. Тому Bazzite є привабливим вибором для людей, які бояться випадкових змін у системі, але стає обмежуючим фактором для більш просунутих користувачів, які хочуть мати повний контроль над системою.

### Manjaro/SteamOS/EndeavourOS/CachyOS

Усі ці дистрибутиви є деривативами Arch Linux і намагаються запропонувати користувачам більш інтуїтивний досвід з функціоналом Arch. Вони зберігають основні принципи Arch, такі як мінімалістичний підхід, використання пакетного менеджера Pacman та доступ до Arch User Repository (AUR), але додають власні налаштування, графічні інтерфейси та інструменти для спрощення установки та управління системою. Це робить їх привабливими для користувачів, які хочуть користуватися перевагами Arch без необхідності глибокого занурення в його складну конфігурацію.

Дистрибутиви перелічено у порядку зростання популярності та рекомендацій, оскільки Manjaro останнім часом має погану репутацію, SteamOS орієнтований на Steam Deck та Steam Machine, через що не всі пристрої досі підтримуються, EndeavourOS пропонує більш чистий Arch-досвід, однак використовує менш актуальну версію ядра, а CachyOS надає сучасні технології ціною стабільності, через що має сумнівну репутацію.
